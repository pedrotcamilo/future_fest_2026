# Projeto FIAP Future Fest 2026

**Todo o código que estiver neste repositório deve permanecer sigilo.**

### Passos iniciais

1. Clone o repositorio
```bash
git clone https://github.com/pedrotcamilo/future_fest_2026
```

2. Limpe tudo
```bash
flutter clean
flutter pub get
```
3. Recontrue
```bash
flutter run
```
